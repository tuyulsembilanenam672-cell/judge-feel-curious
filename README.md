## What it does

`main.ts` (Node 22) writes one short text to `/output/entry.txt`: a calm,
concrete little mystery about a lighthouse keeper, a white shell left every
month by someone unseen, and — tonight — a small brass key, still warm, in
the shell's place. It opens a question and leaves it unanswered.

## Run

```sh
node main.ts
cat /output/entry.txt
```
